# AI-Powered LinkedIn Automation Workflow

## 📌 Overview
This project demonstrates how to automate LinkedIn content creation using **n8n**, **Google Sheets**, and **Google Gemini LLM**.  
It takes ideas from a Google Sheet → generates text with AI → posts directly to LinkedIn.

## ⚙️ Workflow Components
1. **Google Sheets Trigger** – captures new ideas or updates.  
2. **Gemini LLM Node** – generates professional LinkedIn post text.  
3. **LinkedIn Node** – publishes the content automatically.  

## ✨ Features
- End-to-end automation pipeline.  
- Seamless LinkedIn integration.  
- Modular design for easy customization.  

## 🛠️ Tech Stack
- n8n  
- Google Sheets API  
- Gemini LLM  
- LinkedIn API  

## 💡 Use Cases
- Professional LinkedIn updates.  
- Sharing project progress.  
- Content marketing automation.
